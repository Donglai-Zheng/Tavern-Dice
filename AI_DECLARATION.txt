2. AI TOOLS USED

I used ChatGPT for programming guidance and debugging, and ChatGPT Work to help build and improve the GUI. I also used ChatGPT Work to improve the English code comments and prepare the README and AI declaration.

3. STUDENT CONTRIBUTIONS

I came up with the idea for Tavern Dice, inspired by the dice minigame in Kingdom Come: Deliverance II, and decided to make it a local two-player game.

I wrote the dice-rolling and scoring functions in rules.py, as well as the basic gameplay logic in main.py, including player management, dice selection and score updating. I also adapted and implemented the scoring and turn rules for my game and tested the program to make sure they worked correctly.

For the interface, I chose the medieval tavern style and provided specific design requirements and feedback. After testing the first version, I requested improvements to the layout, dice animations, BUST feedback and player transitions. These changes led to the second version of the game.

4. AI ASSISTANCE BY FILE

rules.py

I wrote the dice generation and scoring functions in rules.py, including roll_dice(), has_scoring_dice(), score_same_number(), score_basic_groups(), score_with_straight() and score_selection(). ChatGPT Work later helped improve the English comments and docstrings for the final submission.

main.py

I wrote the basic logic for player management, dice selection and score updating, including the core gameplay operations in player_name(), empty_match(), selected_dice(), on_die_click(), switch_player(), score_and_roll() and score_and_end_turn().

ChatGPT helped connect this logic to the GUI and implement features such as event handling, animation scheduling, screen transitions, menu navigation and target-score input validation. Examples of AI-assisted functions include cancel_pending(), schedule(), pause_pending(), resume_pending(), animate_roll(), animate_bust() and build_ui().

view.py

The GUI code in view.py was generated by ChatGPT Work based on my design requirements and feedback. This includes the Tkinter Canvas layout, backgrounds, dice graphics, menus, buttons, mouse interactions and visual effects.

Examples include background(), draw_die(), draw_menu(), draw_game(), draw_victory(), render(), pointer_click() and build_canvas().

I decided how the interface should look and work, tested it, identified problems and requested changes throughout development.
